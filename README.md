# 🎨 Online AI Art Gallery

## 📌 Overview

Online AI Art Gallery is a web-based platform that combines Artificial Intelligence and digital art to create, showcase, and manage artwork. Users can generate AI-powered images from text prompts, upload their own artwork, explore gallery collections, and interact with creative content through a modern and user-friendly interface.

The project demonstrates the integration of AI-powered image generation with web technologies to provide an engaging platform for artists, designers, and creative enthusiasts.

---

## ✨ Features

* 🔐 User Registration and Login
* 🎨 AI Image Generation from Text Prompts
* 📤 Artwork Upload and Management
* 🖼️ Interactive Art Gallery
* 👤 User Profile Management
* ❤️ Like and Explore Artwork
* 📥 Download Artwork
* 📱 Responsive User Interface
* 🛠️ Admin Dashboard
* 💾 Secure Data Storage

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/PriyankaD2004/Online-AI-Art-Gallery.git
```

### Navigate to Project Directory

```bash
cd Online-AI-Art-Gallery
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

### Open Browser

```text
http://127.0.0.1:5000
```
